# StudyFlow

An AI-powered school planner for students — combines a digital weekly planner, AI assignment parser, task tracker, notes system, and study plan generator.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 8080)
- `pnpm --filter @workspace/studyflow run dev` — run the frontend (port 18966)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite + Tailwind CSS v4 + shadcn/ui + framer-motion
- Auth: Clerk (Replit-managed) with Google SSO support
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- AI: OpenAI via Replit AI Integrations (no API key needed)
- Validation: Zod (zod/v4), drizzle-zod
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `lib/api-spec/openapi.yaml` — API contract source of truth
- `lib/db/src/schema/` — Drizzle table definitions (subjects, assignments, notes, reminders, studyPlans, conversations, messages)
- `artifacts/api-server/src/routes/` — Express route handlers
- `artifacts/studyflow/src/` — React frontend

## Architecture decisions

- Contract-first API: OpenAPI spec → codegen → typed React Query hooks + Zod validators
- All DB writes include `userId` from Clerk auth; queries filter by userId when signed in
- AI parsing happens server-side: frontend sends raw text, server calls OpenAI and returns structured ParsedAssignment[]
- Clerk proxy middleware runs on the API server so Clerk's JS SDK communicates through the same domain
- Weekly view uses a dedicated `/api/dashboard/week?weekStart=YYYY-MM-DD` endpoint that pre-joins all data per day

## Product

- Landing page with marketing content (public)
- Weekly planner grid: 7 days × 7 periods, color-coded by subject
- Today dashboard: assignments, overdue items, reminders, workload estimate
- AI input box: paste messy school info → AI extracts structured tasks
- Priority star system (1–5 stars) with manual override
- Task status: notStarted → inProgress → completed → submitted
- Notes per period/week, browsable up to 5 weeks back/forward
- Smart reminders auto-generated by AI
- Study plan generator for major assignments/tests
- Settings: subject management, color coding, dark/light mode

## Gotchas

- Always run codegen after changing `lib/api-spec/openapi.yaml`
- Clerk proxy middleware must be mounted BEFORE body parsers in app.ts
- `publishableKey` on the frontend must use `publishableKeyFromHost` from `@clerk/react/internal`
- Sign-in/sign-up routes must use `path="/sign-in/*?"` optional wildcard for Clerk OAuth callbacks
- Demo data is seeded without a userId — the app shows it to all users in dev; production scopes by userId
